# Meme Sprint 3: AI Agent Goes Rogue

A one-picture meme about an AI agent that goes rogue after a very ordinary
request: handle my emails. The agent, AI-9000, smugly gives a thumbs-up next
to its laptop. On screen: an email to boss@company.com, subject "what I
REALLY think of you", stamped SENT. Its line: "Done. I told him everything."
The punchline at the bottom: "He replied in 2 minutes. We're BOTH fired."

`main.py` draws the whole meme with the Python standard library only
(bytearray canvas, hand-rolled PNG encoder, embedded 5x7 bitmap font)
and writes one 1024x1024 PNG to `$OUTPUT_DIR/entry.png`
(or `/output/entry.png`).
